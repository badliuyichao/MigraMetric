**工作量计算模型**:
```
总工作量 = 核心迁移工作量 + 报表工作量 + 客开工作量
核心迁移工作量 = Σ (模块基础人天 × 权重系数 × 数据量系数 × 用户数系数)
报表工作量 = 报表数量 × 报表系数 (默认0.5人天/个)
```

**计算流程** (WorkloadCalculationServiceImpl.java):
1. 查询评估记录 → 2. 获取阶梯系数 → 3. 获取报表系数 → 4. 获取已配置模块列表
5. 构建模块工作量列表 → 6. 计算核心迁移工作量 → 7. 计算报表工作量 → 8. 计算客开工作量
9. 计算总工作量 → 10. 更新评估记录

**阶梯匹配服务** (LadderMatchingServiceImpl.java):
- 数据量阶梯: 根据输入的数据量(万条)自动匹配对应阶梯
- 用户数阶梯: 根据输入的用户数(人)自动匹配对应阶梯
- 返回阶梯ID、名称、权重系数

**五大核心模块**:
1. **系统管理** - 系统类型管理、模块库管理 (已完成)
2. **阶梯配置** - 数据量阶梯、用户数阶梯、报表系数配置 (已完成)
3. **项目管理** - 项目CRUD、状态跟踪(DRAFT→IN_PROGRESS→COMPLETED→ARCHIVED) (已完成)
4. **工作量评估** - 四步评估向导(系统确认→模块选择→指标录入→结果展示) (已完成)
5. **报表导出** - Excel/PDF/Word多格式导出 (已完成)

**项目生命周期**: 草稿(DRAFT) → 进行中(IN_PROGRESS) → 已完成(COMPLETED) → 已归档(ARCHIVED)
