## 一、系统简介

### 1.1 系统概述

MigraMetric（异构系统升迁工作量评估系统）是一款专为企业提供异构ERP系统数据迁移工作量评估的工具。通过本系统，用户可以科学地评估异构系统迁移的工作量、时间成本和资源需求。

### 1.2 主要功能

- **项目管理**：创建、编辑、复制、归档迁移项目
- **系统类型管理**：配置源系统和目标系统类型
- **模块库管理**：维护迁移模块库及基础工作量
- **阶梯配置**：配置数据量和用户数阶梯系数
- **工作量评估**：通过4步向导完成工作量评估
- **统计分析**：可视化查看评估结果

### 1.3 技术架构

- 前端：Vue 3 + TypeScript + Element Plus
- 后端：Java 17 + Spring Boot 3
- 数据库：MySQL 8.0
- 认证：JWT Token

## 二、快速开始

### 2.1 登录系统

1. 打开浏览器访问：`http://localhost:3000`
2. 输入用户名和密码（默认管理员：admin / admin123）
3. 点击"登录"按钮进入系统

### 2.2 首页概览

登录成功后进入系统首页，首页展示：
- 项目统计卡片（总数、进行中、已完成）
- 最近评估项目列表
- 系统快捷入口

## 三、项目管理

### 3.1 创建项目

1. 点击左侧菜单"项目管理" -> "项目列表"
2. 点击右上角"创建项目"按钮
3. 填写项目基本信息：
   - 项目名称（必填）
   - 客户名称（必填）
   - 源系统类型（必填，从下拉列表选择）
   - 目标系统类型（必填，从下拉列表选择）
   - 项目负责人
   - 联系方式
   - 项目描述
4. 点击"保存"完成创建

### 3.2 查看项目详情

1. 在项目列表中，点击项目名称进入详情页
2. 详情页展示：
   - 基本信息
   - 评估概况（评估状态、总工作量）
   - 操作按钮（编辑、评估、统计、归档）

### 3.3 编辑项目

1. 在项目详情页，点击"编辑"按钮
2. 修改需要更新的信息
3. 点击"保存"完成修改

**注意**：只有草稿状态的项目可以编辑。

### 3.4 复制项目

1. 在项目列表中，点击操作列的"复制"按钮
2. 确认后系统创建项目副本
3. 新项目状态为"草稿"，可进行编辑

### 3.5 删除项目

1. 在项目列表中，点击操作列的"删除"按钮
2. 确认删除操作

**注意**：只有草稿状态的项目可以删除。

### 3.6 归档项目

1. 在项目列表中，点击操作列的"归档"按钮
2. 确认归档操作

**注意**：只有已完成状态的项目可以归档。归档后项目变为只读状态。

## 四、工作量评估

### 4.1 评估流程概述

工作量评估通过4步向导完成：
1. **系统确认**：确认升迁系统信息
2. **选择模块**：选择需要迁移的模块
3. **填写指标**：录入评估指标数据
4. **查看结果**：查看工作量计算结果

### 4.2 开始评估

1. 在项目详情页，点击"开始评估"按钮
2. 进入评估向导页面

### 4.3 步骤一：系统确认

- 系统自动展示项目的基本信息
- 确认源系统和目标系统是否正确
- 如需修改，点击"返回项目"进行编辑
- 确认无误后，点击"下一步"

### 4.4 步骤二：选择模块

1. 系统展示可选的迁移模块列表
2. 勾选需要迁移的模块（至少选择一项）
3. 可针对每个模块调整加权系数（默认1.0）
4. 点击"下一步"保存配置并进入下一步

**提示**：
- 加权系数范围：0.1 ~ 10.0
- 系数越大，表示该模块复杂度越高

### 4.5 步骤三：填写指标

1. **数据库指标**
   - 数据库表数量：输入需要迁移的表数量
   - 数据量：输入数据总量（单位：万条）
     - 输入后系统自动匹配阶梯并显示系数
   - 用户数量：输入系统用户总数
     - 输入后系统自动匹配阶梯并显示系数

2. **报表指标**
   - 报表数量：输入需要迁移的报表数量

3. **客开情况**
   - 选择是否有定制开发
   - 如有，输入客开模块数量和评估人天

4. **数据清洗需求**（可选）
   - 数据清洗描述：输入清洗需求
   - 数据清洗复杂度：选择简单/中等/复杂

5. 点击"计算工作量"按钮进入结果页

### 4.6 步骤四：查看结果

系统显示工作量评估结果：

1. **工作量汇总**
   - 核心迁移工作量
   - 报表工作量
   - 客开工作量
   - 总工作量

2. **系数说明**
   - 数据量系数
   - 用户数系数
   - 报表系数

3. **模块工作量明细**
   - 各模块的工作量计算明细

4. **评估指标汇总**
   - 录入的各项指标数据

5. 点击"完成评估"按钮，系统更新评估状态

## 五、系统配置

### 5.1 系统类型管理

**功能路径**：系统管理 -> 系统类型管理

**操作说明**：

1. **查询**：输入类型名称，点击"查询"按钮
2. **新增**：点击"新增"按钮，填写类型信息
3. **编辑**：点击操作列"编辑"按钮
4. **删除**：点击操作列"删除"按钮
5. **启用/禁用**：点击操作列相应按钮

**字段说明**：
- 类型名称：系统类型的显示名称
- 类型编码：系统类型的唯一标识
- 描述：详细说明
- 排序：列表显示顺序
- 状态：启用/禁用

### 5.2 模块库管理

**功能路径**：系统管理 -> 模块库管理

**操作说明**：

1. **查询**：输入模块名称或选择分类
2. **新增**：点击"新增"按钮
3. **编辑**：点击操作列"编辑"按钮
4. **删除**：点击操作列"删除"按钮
5. **启用/禁用**：点击操作列相应按钮

**字段说明**：
- 模块名称：模块的显示名称
- 分类：模块所属分类（如：财务、供应链、生产等）
- 基础人天：该模块的标准工作量
- 默认系数：该模块的默认加权系数
- 描述：详细说明

### 5.3 数据量阶梯配置

**功能路径**：阶梯配置 -> 数据量阶梯

**操作说明**：

1. **查看阶梯列表**：系统展示各阶梯的区间和系数
2. **新增**：点击"新增"按钮
3. **编辑**：点击操作列"编辑"按钮
4. **删除**：点击操作列"删除"按钮

**阶梯系数说明**：
| 阶梯类型 | 数据量范围 | 系数 |
|---------|-----------|------|
| 小型 | 0-10万条 | 0.8 |
| 中型 | 10万-1000万条 | 1.0 |
| 大型 | 1000万-10000万条 | 1.5 |
| 超大型 | 10000万条以上 | 2.0 |

### 5.4 用户数阶梯配置

**功能路径**：阶梯配置 -> 用户数阶梯

**阶梯系数说明**：
| 阶梯类型 | 用户数范围 | 系数 |
|---------|-----------|------|
| 小规模 | 0-100人 | 1.0 |
| 中规模 | 100-500人 | 1.2 |
| 大规模 | 500-1000人 | 1.5 |
| 超大规模 | 1000人以上 | 2.0 |

### 5.5 报表系数配置

**功能路径**：系统配置 -> 报表系数配置

**配置项说明**：
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 报表系数 | 每个报表的标准工作量（人天） | 0.5 |
| 小报表阈值 | 少于该数量的报表为小报表 | 20 |
| 中报表阈值 | 少于该数量的报表为中报表 | 50 |
| 大报表阈值 | 少于该数量的报表为大报表 | 100 |
| 客开日单价 | 定制开发的日工资标准（元/天） | 1500 |

## 七、常见问题

### 7.1 登录问题

**Q：忘记密码怎么办？**
A：请联系系统管理员重置密码。

**Q：登录提示"Token无效"？**
A：请重新登录获取新的Token。

### 7.2 评估问题

**Q：为什么数据量/用户数没有匹配到阶梯？**
A：请检查阶梯配置，确保输入值在配置的阶梯范围内。

**Q：如何调整单个模块的复杂度？**
A：在评估步骤二"选择模块"中，可以调整每个模块的加权系数。

**Q：客开工作量如何计算？**
A：客开工作量 = 客开模块数量 × 每个模块的平均人天，可在报表配置中调整日单价。

### 7.3 数据问题

**Q：为什么删除项目失败？**
A：只有草稿状态的项目可以删除。已完成或归档的项目需要先重置状态。

**Q：归档的项目可以恢复吗？**
A：归档操作不可逆，请谨慎操作。

## 八、附录

### 8.1 工作量计算公式

```
总工作量 = 核心迁移工作量 + 报表工作量 + 客开工作量

核心迁移工作量 = Σ(基础人天 × 加权系数 × 数据量系数 × 用户数系数)

报表工作量 = 报表数量 × 报表系数

客开工作量 = 客开人天（手动输入）
```

### 8.2 术语表

| 术语 | 说明 |
|------|------|
| 基础人天 | 模块的标准工作量 |
| 加权系数 | 模块复杂度调整系数 |
| 数据量系数 | 根据数据量匹配的阶梯系数 |
| 用户数系数 | 根据用户数匹配的阶梯系数 |
| 报表系数 | 每个报表的标准工作量 |
| 客开 | 定制开发 |

### 8.3 联系方式

如有问题，请联系系统管理员或技术支持团队。
