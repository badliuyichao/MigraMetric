## 三、数据库部署

### 3.1 创建数据库

```sql
CREATE DATABASE migrametric CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 3.2 初始化数据

```bash
mysql -u root -p migrametric < docs/init-db.sql
```

### 3.3 数据库配置

编辑后端配置文件 `migrametric-server/src/main/resources/application.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/migrametric?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false
    username: root
    password: your_password
    driver-class-name: com.mysql.cj.jdbc.Driver
```

## 四、后端部署

### 4.1 开发环境运行

```bash
cd migrametric-server
mvn spring-boot:run
```

服务启动后访问：`http://localhost:8080`

### 4.2 构建JAR包

```bash
cd migrametric-server
mvn clean package -DskipTests
```

构建产物：`target/migrametric-server-1.0.0-SNAPSHOT.jar`

### 4.3 生产环境运行

```bash
java -jar migrametric-server-1.0.0-SNAPSHOT.jar
```

### 4.4 开机自启配置（Linux Systemd）

创建服务文件 `/etc/systemd/system/migrametric.service`：

```ini
[Unit]
Description=MigraMetric Server
After=network.target mysql.service

[Service]
Type=simple
User=your_user
WorkingDirectory=/path/to/migrametric-server
ExecStart=/usr/bin/java -jar target/migrametric-server-1.0.0-SNAPSHOT.jar
Restart=always

[Install]
WantedBy=multi-user.target
```

启动服务：

```bash
sudo systemctl daemon-reload
sudo systemctl enable migrametric
sudo systemctl start migrametric
```

### 4.5 后端配置参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| server.port | 服务端口 | 8080 |
| spring.datasource.url | 数据库连接 | - |
| jwt.secret | JWT密钥 | - |
| jwt.expiration | Token过期时间(毫秒) | 7200000 |

可通过环境变量覆盖：

```bash
java -jar migrametric-server-1.0.0-SNAPSHOT.jar --server.port=8081
```

## 五、前端部署

### 5.1 安装依赖

```bash
cd migrametric-web
pnpm install
```

### 5.2 开发环境运行

```bash
pnpm dev
```

访问：`http://localhost:3000`

### 5.3 生产构建

```bash
pnpm build
```

构建产物：`dist/` 目录

### 5.4 前端配置

编辑 `vite.config.ts` 中的代理配置：

```typescript
server: {
  proxy: {
    '/api': {
      target: 'http://localhost:8080',  // 后端地址
      changeOrigin: true,
      rewrite: (path) => path.replace(/^\/api/, '')
    }
  }
}
```

### 5.5 Nginx 配置

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    root /path/to/migrametric-web/dist;
    index index.html;

    # SPA 路由支持
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 代理
    location /api {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # 静态资源缓存
    location /assets {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    # Gzip 压缩
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml;
    gzip_min_length 1000;
}
```

## 六、Docker 部署（可选）

### 6.1 Docker Compose 配置

创建 `docker-compose.yml`：

```yaml
version: '3.8'

services:
  mysql:
    image: mysql:8.0
    container_name: migrametric-mysql
    environment:
      MYSQL_ROOT_PASSWORD: root_password
      MYSQL_DATABASE: migrametric
      MYSQL_USER: migrametric
      MYSQL_PASSWORD: migrametric_password
    ports:
      - "3306:3306"
    volumes:
      - mysql_data:/var/lib/mysql
      - ./docs/init-db.sql:/docker-entrypoint-initdb.d/init.sql
    command: --default-authentication-plugin=mysql_native_password

  server:
    build:
      context: ./migrametric-server
      dockerfile: Dockerfile
    container_name: migrametric-server
    ports:
      - "8080:8080"
    environment:
      SPRING_DATASOURCE_URL: jdbc:mysql://mysql:3306/migrametric?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
      SPRING_DATASOURCE_USERNAME: migrametric
      SPRING_DATASOURCE_PASSWORD: migrametric_password
    depends_on:
      - mysql

  web:
    image: nginx:alpine
    container_name: migrametric-web
    ports:
      - "80:80"
    volumes:
      - ./migrametric-web/dist:/usr/share/nginx/html
      - ./nginx.conf:/etc/nginx/conf.d/default.conf
    depends_on:
      - server

volumes:
  mysql_data:
```

### 6.2 后端 Dockerfile

创建 `migrametric-server/Dockerfile`：

```dockerfile
FROM eclipse-temurin:17-jdk-alpine AS build
WORKDIR /app
COPY pom.xml .
COPY src ./src
RUN apt-get update && apt-get install -y maven
RUN mvn clean package -DskipTests

FROM eclipse-temurin:17-jre-alpine
WORKDIR /app
COPY --from=build /app/target/*.jar app.jar
ENTRYPOINT ["java", "-jar", "app.jar"]
```

### 6.3 启动 Docker 服务

```bash
docker-compose up -d
```

## 七、Nginx 配置完整示例

```nginx
user nginx;
worker_processes auto;
error_log /var/log/nginx/error.log;
pid /run/nginx.pid;

events {
    worker_connections 1024;
}

http {
    include /etc/nginx/mime.types;
    default_type application/octet-stream;

    log_format main '$remote_addr - $remote_user [$time_local] "$request" '
                    '$status $body_bytes_sent "$http_referer" '
                    '"$http_user_agent" "$http_x_forwarded_for"';

    access_log /var/log/nginx/access.log main;

    sendfile on;
    tcp_nopush on;
    tcp_nodelay on;
    keepalive_timeout 65;
    types_hash_max_size 2048;

    # Gzip 压缩
    gzip on;
    gzip_vary on;
    gzip_proxied any;
    gzip_comp_level 6;
    gzip_types text/plain text/css text/xml application/json application/javascript
               application/rss+xml application/atom+xml image/svg+xml
               application/xml application/xml+rss;

    # 上游服务器
    upstream backend {
        server 127.0.0.1:8080;
        keepalive 32;
    }

    server {
        listen 80;
        server_name migrametric.example.com;

        # 安全响应头
        add_header X-Frame-Options "SAMEORIGIN" always;
        add_header X-Content-Type-Options "nosniff" always;
        add_header X-XSS-Protection "1; mode=block" always;

        # 前端文件
        root /var/www/migrametric;
        index index.html;

        # 静态资源
        location /assets/ {
            expires 1y;
            add_header Cache-Control "public, immutable";
        }

        # API 请求
        location /api/ {
            proxy_pass http://backend;
            proxy_http_version 1.1;
            proxy_set_header Connection "";
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;

            # 超时设置
            proxy_connect_timeout 60s;
            proxy_send_timeout 60s;
            proxy_read_timeout 60s;
        }

        # Swagger UI
        location /swagger-ui.html {
            proxy_pass http://backend;
            proxy_set_header Host $host;
        }

        location /v3/api-docs {
            proxy_pass http://backend;
            proxy_set_header Host $host;
        }

        # SPA 路由
        location / {
            try_files $uri $uri/ /index.html;
        }

        # 健康检查
        location /health {
            access_log off;
            return 200 "healthy\n";
            add_header Content-Type text/plain;
        }
    }
}
```

## 十、备份与恢复

### 10.1 数据库备份

```bash
# 完整备份
mysqldump -u root -p migrametric > backup_$(date +%Y%m%d).sql

# 压缩备份
mysqldump -u root -p migrametric | gzip > backup_$(date +%Y%m%d).sql.gz
```

### 10.2 数据恢复

```bash
# 从备份恢复
mysql -u root -p migrametric < backup_20260325.sql

# 从压缩备份恢复
gunzip < backup_20260325.sql.gz | mysql -u root -p migrametric
```

### 10.3 自动备份脚本

创建定时任务 `crontab -e`：

```cron
# 每天凌晨2点备份
0 2 * * * /path/to/backup.sh >> /var/log/backup.log 2>&1

# 保留最近30天备份
0 3 * * * find /path/to/backups -name "*.sql.gz" -mtime +30 -delete
```

## 十一、故障排查

### 11.1 常见问题

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 后端启动失败 | 端口被占用 | 检查端口占用 `netstat -tlnp | grep 8080` |
| 数据库连接失败 | 数据库未启动或配置错误 | 检查 MySQL 服务状态和连接配置 |
| 前端无法访问API | 代理配置错误 | 检查 Nginx 代理配置 |
| Token 过期 | JWT 配置问题 | 检查 jwt.secret 和 jwt.expiration 配置 |

### 11.2 日志查看

```bash
# 后端日志
tail -f logs/migrametric.log

# Nginx 错误日志
tail -f /var/log/nginx/error.log

# Nginx 访问日志
tail -f /var/log/nginx/access.log
```

### 11.3 端口检查

```bash
# 检查端口占用
netstat -tlnp | grep -E '(8080|3000|3306)'

# 检查进程
ps aux | grep -E '(java|node|mysql)'
```
