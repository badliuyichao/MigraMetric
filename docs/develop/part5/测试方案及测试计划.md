## 一、测试概述

### 1.1 测试范围

本测试计划针对第五阶段完成的 4 个子任务：

| 序号 | 任务名称 | 功能描述 | 后端 | 前端 |
|------|---------|---------|------|------|
| 5.1 | 统计分析图表 | 饼图、柱状图、雷达图展示 | ✅ | ✅ |
| 5.2 | Excel导出 | Apache POI导出Excel | ✅ | ✅ |
| 5.3 | PDF导出 | PDF生成 | ✅ | ✅ |
| 5.4 | Word导出 | Word模板导出 | ✅ | ✅ |

### 1.2 测试目标

1. **功能完整性**：所有统计图表正常显示，报告导出功能正常工作
2. **图表准确性**：图表数据与评估结果一致
3. **导出格式正确**：Excel/PDF/Word格式正确、内容完整
4. **文件命名规范**：遵循 `{客户名称}_{项目名称}_工作量评估报告_{日期}.{格式}` 规则
5. **前后端集成**：API 接口与前端页面正常交互
6. **代码质量**：通过 ESLint、TypeScript 检查

### 1.3 技术栈

#### 后端导出技术
- **Excel导出**：Apache POI 5.x
- **PDF导出**：iText 7.x 或 OpenPDF
- **Word导出**：Apache POI Word (HWPF/XWPF)

#### 前端图表技术
- **图表库**：ECharts 5.x
- **图表类型**：
  - 饼图（Pie Chart）：工作量类型分布
  - 柱状图（Bar Chart）：模块工作量对比
  - 雷达图（Radar Chart）：多维度评估指标

## 二、统计图表数据模型

### 2.1 工作量类型分布数据

```typescript
interface WorkloadTypeDistribution {
  type: '核心迁移' | '报表迁移' | '客开定制'
  workload: number  // 工作量（人天）
  percentage: number  // 占比（%）
}
```

**示例数据：**
| 类型 | 工作量（人天） | 占比 |
|------|--------------|------|
| 核心迁移 | 111.38 | 71.3% |
| 报表迁移 | 25.00 | 16.0% |
| 客开定制 | 20.00 | 12.7% |

### 2.2 模块工作量对比数据

```typescript
interface ModuleWorkloadComparison {
  moduleName: string
  workload: number  // 工作量（人天）
  baseWorkload: number  // 基础人天
  weight: number  // 加权系数
}
```

**示例数据：**
| 模块名称 | 基础人天 | 加权系数 | 工作量（人天） |
|---------|---------|---------|--------------|
| 财务管理 | 15 | 1.3 | 43.88 |
| 供应链管理 | 20 | 1.5 | 67.50 |
| 生产管理 | 25 | 1.8 | 101.25 |

### 2.3 多维度评估指标数据

```typescript
interface MultiDimensionIndicators {
  dimension: string  // 维度名称
  value: number  // 归一化值（0-100）
  actualValue: string  // 实际值
}
```

**维度定义：**
| 维度 | 归一化公式 | 说明 |
|------|----------|------|
| 数据量 | min(value/10000, 1) × 100 | 0-10000万条 |
| 用户数 | min(value/1000, 1) × 100 | 0-1000人 |
| 模块数 | min(value/20, 1) × 100 | 0-20个模块 |
| 报表数 | min(value/100, 1) × 100 | 0-100个报表 |
| 客开情况 | hasCustomDev ? 80 : 20 | 是否有客开 |
