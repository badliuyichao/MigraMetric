### 2.3 数据验证

| 字段 | 类型 | 必填 | 验证规则 |
|------|------|------|---------|
| username | String | 是 | 3-50字符，唯一 |
| password | String | 是（创建时） | 6-100字符，BCrypt加密 |
| name | String | 是 | 最多50字符 |
| email | String | 否 | 邮箱格式验证 |
| phone | String | 否 | 最多20字符 |
| role | String | 是 | ADMIN或USER |
| status | Integer | 是 | 0或1 |

### 2.4 业务规则

1. 用户名全局唯一，不能重复
2. 密码必须使用BCrypt加密存储
3. 不能删除ADMIN角色的用户
4. 不能禁用ADMIN角色的用户
5. 默认创建的用户状态为启用

### 4.3 使用方式

#### 操作日志注解

在 Controller 方法上添加 `@OperLog` 注解，自动记录操作日志：

```java
@OperLog(module = "项目管理", operationType = "CREATE", description = "创建项目")
@PostMapping
public Result<ProjectVO> createProject(@RequestBody ProjectCreateDTO dto) {
    // 业务逻辑
}
```

#### 切面自动记录的信息

- 操作模块
- 操作类型
- 操作描述
- 请求方法/URL
- 请求参数
- 操作用户信息
- IP地址和登录地点
- 执行时长
- 操作状态（成功/失败）
- 错误信息（如有）
