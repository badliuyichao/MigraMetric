## 一、项目概述

### 1.1 项目目标

构建一个Web应用系统，用于评估异构ERP系统数据迁移的工作量，为企业提供量化、可视化的评估报告。

### 1.2 技术栈

| 层级 | 技术选型 |
|------|---------|
| 前端 | Vue 3 + TypeScript + Element Plus + ECharts + Vite + pnpm |
| 后端 | Java 17 + Spring Boot 3 + MyBatis-Plus |
| 数据库 | MySQL 8.0 |
| 认证 | JWT |
| API文档 | Swagger/OpenAPI 3 |

### 1.3 项目结构

```
MigraMetric/
├── docs/                      # 项目文档
│   ├── architecture/          # 架构设计文档
│   └── develop/               # 开发计划文档
├── migrametric-web/           # 前端项目
├── migrametric-server/        # 后端项目
└── scripts/                   # 部署脚本
```

**具体任务详情**：

#### 4.1 阶梯匹配服务
```

- LadderMatchingService
- 数据量阶梯匹配逻辑
- 用户数阶梯匹配逻辑
- 阶梯查询接口

计算公式：
- 数据量阶梯：根据min_volume <= 数据量 < max_volume匹配
- 用户数阶梯：根据min_count <= 用户数 < max_count匹配
```

#### 4.2 评估步骤一 - 系统确认
```
前端任务：
- 步骤指示器组件
```

```
前端任务：
- 模块列表（复选框）
- 基础人天展示
- 默认系数展示
- 调整系数输入框
- 已选统计
- 下一步校验（至少选一个）
```

#### 4.4 评估步骤三 - 指标录入
```
后端任务：
- 指标保存接口
- 指标验证逻辑

前端任务：
- 已选模块信息展示
- 数据库表数量输入
- 数据量输入（自动匹配阶梯）
- 用户数输入（自动匹配阶梯）
- 报表数量输入
- 客开情况单选
- 客开人天输入（条件显示）
- 数据清洗描述
- 数据清洗复杂度
```

#### 4.5 工作量计算服务
```
后端任务：
- WorkloadCalculationService
- 核心迁移工作量计算
- 报表工作量计算
- 客开工作量计算
- 总工作量计算
- 工作量明细生成

计算公式：
核心迁移工作量 = Σ(基础人天 × 加权系数 × 数据量系数 × 用户数系数)
报表工作量 = 报表数量 × 报表系数
客开工作量 = 客开人天（手动输入）
总工作量 = 核心迁移工作量 + 报表工作量 + 客开工作量
```

#### 4.6 评估步骤四 - 结果展示
```

前端任务：
```

## 六、代码提交规范

```bash
# 提交格式
<type>(<scope>): <subject>

# 示例
feat(system): 新增系统管理功能
fix(evaluation): 修复工作量计算系数错误
docs(readme): 更新README文档
style(ui): 调整登录页面样式
refactor(service): 重构工作量计算服务
test(unit): 添加工作量计算单元测试
chore(build): 更新构建配置
```

## 七、注意事项

### 7.1 开发规范
1. 严格遵循架构文档中的命名规范
2. 代码注释完整，重要逻辑需说明
3. 提交前执行代码检查
4. 及时更新相关文档

### 7.2 Git规范
1. 从develop分支创建功能分支
2. 频繁commit，保持原子性
3. PR描述详细，说明影响范围
4. 代码审查通过后方可合并

### 7.3 测试规范
1. 新功能必须有测试用例
2. 修改bug时添加回归测试
3. 核心计算逻辑必须覆盖
4. 提交前运行本地测试
