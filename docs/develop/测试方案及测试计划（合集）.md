### 5.2 工作量计算模型

#### 计算公式

**总工作量**
```
总工作量（人天） = 核心迁移工作量 + 报表工作量 + 客开工作量
```

**核心迁移工作量**
```
核心迁移工作量 = Σ(各模块基础人天 × 模块加权系数 × 数据量阶梯系数 × 用户数阶梯系数)
```

**报表工作量**
```
报表工作量 = 报表数量 × 报表系数
```

**客开工作量**
```
客开工作量 = 客开评估人天数（手动输入）
```

#### 计算示例

**假设条件：**
- 财务管理模块：基础人天15天，调整系数1.3
- 供应链管理模块：基础人天20天，使用默认系数1.5
- 数据量：500万条（阶梯系数1.5）
- 用户数：600人（阶梯系数1.5）
- 报表数量：50个
- 报表系数：0.5人天/个
- 客开工作量：20人天

**计算过程：**
```
财务管理模块工作量 = 15 × 1.3 × 1.5 × 1.5 = 43.875人天
供应链管理模块工作量 = 20 × 1.5 × 1.5 × 1.5 = 67.5人天
核心迁移工作量 = 43.875 + 67.5 = 111.375人天
报表工作量 = 50 × 0.5 = 25人天
客开工作量 = 20人天
总工作量 = 111.375 + 25 + 20 = 156.375人天
```
