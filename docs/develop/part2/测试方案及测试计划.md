## 六、集成测试建议

### 6.1 端到端测试场景

| 场景 | 测试步骤 | 预期结果 |
|------|---------|---------|
| 系统类型完整流程 | 创建 → 查询 → 编辑 → 禁用 → 启用 → 删除 | 全流程正常 |
| 模块管理完整流程 | 创建 → 按系统查询 → 编辑 → 删除 | 全流程正常 |
| 阶梯配置完整流程 | 创建阶梯 → 上移 → 下移 → 删除 | 排序正确更新 |

### 6.2 异常场景测试

| 场景 | 输入 | 预期结果 |
|------|------|---------|
| 创建重复系统类型 | SAP → SAP | 返回错误：系统名称已存在 |
| 删除被引用的系统类型 | 删除已关联模块的系统 | 返回错误：系统被模块引用 |
| 阶梯范围重叠 | 创建 [100-200] 时已有 [150-250] | 返回错误：阶梯范围重叠 |
| 越权操作 | 无 token 访问管理接口 | 返回 401 未授权 |

## 七、测试执行命令

### 7.1 后端测试

```bash
# 运行所有测试
cd migrametric-server
mvn clean test

# 运行指定模块测试
mvn test -Dtest=SystemTypeServiceTest
mvn test -Dtest=ModuleServiceTest
mvn test -Dtest=DataVolumeLadderServiceTest
mvn test -Dtest=UserCountLadderServiceTest
mvn test -Dtest=ReportConfigServiceTest

# 生成覆盖率报告
mvn test jacoco:report
```

### 7.2 前端测试

```bash
# 运行所有测试
cd migrametric-web
npm run test:unit

# 运行指定测试
npm test -- --run src/api/system/types.test.ts
```
