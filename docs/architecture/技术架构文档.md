## 一、系统概述

### 1.1 项目简介

**项目名称**：MigraMetric（异构系统升迁工作量评估系统）

**项目目标**：为企业提供异构ERP系统数据迁移工作量的科学评估工具，通过Web应用实现评估流程的便捷化、结果的可视化。

### 1.2 技术选型总结

| 层级 | 技术栈 | 说明 |
|------|--------|------|
| **前端** | Vue 3 + TypeScript | 渐进式框架，类型安全，生态丰富 |
| **前端UI** | Element Plus | Vue 3 组件库，企业级设计 |
| **前端图表** | ECharts | 百度开源图表库，功能强大 |
| **前端构建** | Vite | 下一代前端构建工具，快速高效 |
| **前端包管理** | pnpm | 高性能包管理器，节省磁盘空间 |
| **后端** | Java 17 + Spring Boot 3 | 企业级框架，稳定可靠 |
| **持久层** | MyBatis-Plus | 简化MyBatis开发，支持 CRUD 增强 |
| **数据库** | MySQL 8.0 | 开源关系型数据库，社区活跃 |
| **API文档** | Swagger/OpenAPI 3 | 自动生成API文档 |
| **日志** | SLF4J + Logback | 日志框架门面+实现 |
| **认证** | JWT | 无状态Token认证 |
| **代码规范** | ESLint + Prettier | 前端代码检查和格式化 |
| **代码规范** | Checkstyle | 后端代码规范检查 |

### 1.4 系统模块划分

基于DDD（领域驱动设计）思想，系统分为以下领域：

| 领域 | 说明 | 核心功能 |
|------|------|---------|
| 配置域 (Configuration) | 系统基础配置数据管理 | 系统类型、模块库、阶梯配置、报表系数 |
| 项目域 (Project) | 评估项目生命周期管理 | 项目CRUD、状态管理 |
| 评估域 (Evaluation) | 工作量评估核心业务逻辑 | 模块选择、指标录入、工作量计算 |
| 报告域 (Report) | 评估报告生成和输出 | 报告生成、多格式导出 |
| 用户域 (User) | 用户身份认证和权限管理 | 用户管理、角色管理、认证授权 |

### 2.4 分层架构说明

#### 2.4.1 Controller层
- 职责：接收HTTP请求，参数校验，调用Service层
- 禁止：业务逻辑直接写在Controller中
- 要求：方法注释清晰，参数注解完整

#### 2.4.2 Service层
- 职责：处理业务逻辑，事务管理
- 分类：
  - Interface：定义业务接口
  - Impl：实现业务逻辑
- 要求：方法职责单一，事务边界清晰

#### 2.4.3 Repository层
- 职责：数据持久化操作
- 实现：MyBatis-Plus提供的BaseMapper + 自定义XML
- 要求：SQL编写规范，参数使用OGNL表达式

#### 2.4.4 DTO/VO层
- DTO (Data Transfer Object)：数据传输对象，用于接口请求参数
- VO (View Object)：视图对象，用于接口响应数据
- 要求：字段与接口文档一致，命名清晰

    public LoginResult login(LoginDTO loginDTO) {
        // 1. 查询用户
        User user = userMapper.selectByUsername(loginDTO.getUsername());

        // 2. 校验用户状态
        if (user == null || user.getStatus() == 0) {
            throw new BusinessException(ResultCode.UNAUTHORIZED, "用户名或密码错误");
        }

        // 3. 校验密码
        if (!passwordEncoder.matches(loginDTO.getPassword(), user.getPassword())) {
            throw new BusinessException(ResultCode.UNAUTHORIZED, "用户名或密码错误");
        }

        // 4. 生成Token
        String token = generateToken(user);
        return new LoginResult(token, jwtProperties.getExpireTime());
    }
}

 * JWT认证过滤器
 */
@Component
public class JwtAuthenticationTokenFilter extends OncePerRequestFilter {

    @Resource
    private JwtTokenService jwtTokenService;

    @Override
    protected void doFilterInternal(HttpServletRequest request,
                                    HttpServletResponse response,
                                    FilterChain filterChain) throws ServletException, IOException {
        String token = getTokenFromRequest(request);

        if (StringUtils.hasText(token) && jwtTokenService.validateToken(token)) {
            String username = jwtTokenService.getUsernameFromToken(token);
            LoginUser loginUser = jwtTokenService.getLoginUserFromToken(token);

            if (loginUser != null) {
                UsernamePasswordAuthenticationToken authenticationToken =
                    new UsernamePasswordAuthenticationToken(loginUser, null, loginUser.getAuthorities());
                authenticationToken.setDetails(new WebAuthenticationDetailsSource().buildDetails(request));
                SecurityContextHolder.getContext().setAuthentication(authenticationToken);
            }
        }

        filterChain.doFilter(request, response);
    }
}

public class DataMaskingUtil {

    /**
     * 手机号脱敏
     * 138****5678
     */
    public static String maskPhone(String phone) {
        if (StringUtils.isEmpty(phone) || phone.length() < 7) {
            return phone;
        }
        return phone.substring(0, 3) + "****" + phone.substring(phone.length() - 4);
    }

    /**
     * 邮箱脱敏
     * t***@example.com
     */
    public static String maskEmail(String email) {
        if (StringUtils.isEmpty(email) || !email.contains("@")) {
            return email;
        }
        String[] parts = email.split("@");
        String name = parts[0];
        if (name.length() <= 2) {
            return name.charAt(0) + "***@" + parts[1];
        }
        return name.charAt(0) + "***@" + parts[1];
    }

    /**
     * 身份证脱敏
     * 110***********1234
     */
    public static String maskIdCard(String idCard) {
        if (StringUtils.isEmpty(idCard) || idCard.length() < 8) {
            return idCard;
        }
        return idCard.substring(0, 3) + "***********" + idCard.substring(idCard.length() - 4);
    }

#!/bin/bash
# deploy.sh - 后端部署脚本

APP_NAME="migrametric-server"
APP_JAR="${APP_NAME}.jar"
APP_PORT=${APP_PORT:-8080}
LOG_DIR="/var/log/migrametric"

# 创建日志目录
mkdir -p ${LOG_DIR}

# 停止旧进程
PID=$(ps -ef | grep ${APP_JAR} | grep -v grep | awk '{print $2}')
if [ -n "$PID" ]; then
    echo "Stopping old process: $PID"
    kill -9 $PID
fi

# 启动新进程
echo "Starting ${APP_NAME}..."
nohup java -jar ${APP_JAR} \
  --spring.profiles.active=prod \
  --server.port=${APP_PORT} \
  --logging.file.name=${LOG_DIR}/${APP_NAME}.log \
  > /dev/null 2>&1 &

echo "Started with PID: $!"

# 等待启动完成
sleep 10

# 检查启动状态
if curl -s http://localhost:${APP_PORT}/health > /dev/null; then
    echo "Application started successfully!"
else
    echo "Application failed to start. Check logs at ${LOG_DIR}/${APP_NAME}.log"
fi
